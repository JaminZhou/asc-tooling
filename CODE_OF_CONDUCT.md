# Code of Conduct

This project welcomes constructive contributions around App Store Connect
automation, release tooling, and documentation quality.

## Expected Behavior

- Be respectful and direct.
- Keep technical disagreement focused on code, data, workflows, and risk.
- Provide reproducible commands, inputs, and observed output when reporting
  problems.
- Treat App Store Connect credentials, browser sessions, product metadata, and
  release state as sensitive.

## Unacceptable Behavior

- Harassment, personal attacks, discrimination, or threats.
- Posting `.p8` keys, cookies, tokens, account identifiers, unpublished product
  details, or other secrets in public issues or pull requests.
- Pushing the project toward hidden side effects or unclear App Store Connect
  mutations.
- Presenting experimental browser-session helpers as stable CI-ready workflows.

## Enforcement

Maintainers may edit, hide, or remove content that violates this code of
conduct and may temporarily or permanently limit participation in the project.

Report security-sensitive issues through [SECURITY.md](SECURITY.md), not public
issues.
